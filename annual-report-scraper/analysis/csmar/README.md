# 对照检验（CSMAR 全部 A 股）

实证修改稿（第 4、5 版）中入表选择、双重差分、稳健性、异质性与正文零散数字的计算程序（对应论文表号以第 5 版为准）。CSMAR 原始数据有使用许可，**不提交到仓库**；重现时把下载的 zip 解压到本目录的 `csmar/` 子文件夹。

运行环境：`pip install pandas numpy statsmodels scipy pyfixest matplotlib openpyxl differences wildboottest`。第 11 步之后的程序需要先跑完第 0—2 步。`did_modern.py` 的野自助法较慢（约 10 分钟）。

主要结论（2026-10-09 运行）：
- 数据核对：236 份年报的总资产 235 份与 CSMAR 完全一致；数据资源期末余额 220 份完全一致，其余 16 份为仅附注披露、CSMAR 记为 0 的公司。CSMAR 列报数据资源的 A 股公司 2024 年 91 家、2025 年 129 家，高金名单覆盖 90、127 家。
- 入表选择（非金融，首次入表 123 家，平均入表率 1.23%）：规模、国有、上年研发资本化率为正；上年利润下滑为负（LPM −0.68 个百分点，p<0.01），上年亏损为负（p<0.1），微利不显著；四种稳健性设定下结论不变。
- 双重差分：研发资本化率 +2.1 个百分点（t=1.53），资本化研发/总资产、|可操纵应计|（三种应计模型）、微利、亏损均不显著；匹配后结论不变；入表前无预期效应。研发资本化率仅在卡尺匹配（p<0.1）和行业内随机置换（p=0.048）下显著，按「行业 × 是否资本化研发」分层置换后 p=0.070，属于弱证据。
- 第 5 版补充（2026-10-09 运行）：Callaway-Sant'Anna 估计的研发资本化率 ATT 为 0.0234（p=0.168），Sun-Abraham 为 0.0183，堆叠 DID 为 0.0206，均不显著；Goodman-Bacon 分解中以已入表企业为对照的比较权重仅约 0.1%；野自助法 p 值与聚类稳健 p 值几乎相同；可操纵应计利润的 80% 功效最小可检测效应为 0.0079（约为 2023 年入表企业均值的 20%）。Firth 与 King-Zeng 校正后入表选择结论不变。
- 第 6 版补充（2026-10-10 运行）：真实盈余管理三项指标及合计的双向固定效应估计均不显著（合计 −0.0026，95% 置信区间 [−0.0159, 0.0106]）；Callaway-Sant'Anna 的合计为 −0.0186（p<0.05），但事件研究显示 2021 年即有差异，不解读为下降。入表选择加入质押、分析师、机构持股、四大后，原结论不变，质押比例越高越不倾向入表（线性概率模型 p<0.05）；2026 年上半年首次入表的非金融企业仅 10 家，并入后结论不变。入表后审计费用相对下降约 4%–7%（控制国企×年度、行业×年度、规模组×年度、事务所变更后仍显著），分析师关注、机构持股不变；年报问询函的增加集中在少数亏损企业，加入上述固定效应后不显著。税后口径下 2024 年非金融企业入表额合计由 20.74 亿元降至 17.16 亿元，重点关注企业数基本不变。
