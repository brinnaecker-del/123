# 对照检验（CSMAR 全部 A 股）

论文第五部分（五）、表 3、表 4 的计算程序。CSMAR 原始数据有使用许可，**不提交到仓库**；重现时把下载的 zip 解压到本目录的 `csmar/` 子文件夹。

| 步骤 | 程序 | 作用 |
|---|---|---|
| 0 | `prepare_raw.py`（调用 `load.py`） | 读 CSMAR xlsx，存为 pickle |
| 1 | `master.py` | 合并资产负债表、利润表、现金流量表、研发投入、公司文件、股权性质，2021–2025，剔除 B 股 |
| 2 | `prep.py` | 构造入表处理组（高金名单 ∪ CSMAR 列报数据资源）、研发资本化率、修正琼斯模型可操纵应计、微利等 |
| 3 | `final_tables.py csmar/analysis.pkl 输出.json` | 表 3（入表选择：线性概率模型、Logit）与表 4（双重差分：全样本、倾向得分匹配），附事件研究系数 |
| — | `did2.py`、`did3.py` | 探索性检验（调节效应、亏损企业的微利迹象），论文正文只引用了 did3 的结论 |

运行环境：`pip install pandas numpy statsmodels pyfixest openpyxl`。

主要结论（2026-10-09 运行）：
- 数据核对：236 份年报的总资产 235 份与 CSMAR 完全一致；数据资源期末余额 219 份完全一致，其余 17 份 CSMAR 记为 0：16 份仅附注披露，1 份为神马股份 2024（报表错位，已按开发支出项下 26,772,194.00 修正）。CSMAR 列报数据资源的 A 股公司 2024 年 91 家、2025 年 129 家，高金名单覆盖 90、127 家。
- 入表选择：规模、国有、上年研发资本化率为正；上年利润下滑为负（LPM −0.64 个百分点，p=0.014）；亏损、微利不显著。
- 双重差分：研发资本化率 +2.1 个百分点（不显著），资本化研发/总资产、|可操纵应计|、微利、亏损均不显著；匹配后结论不变；入表前无预期效应。
