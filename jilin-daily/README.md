# 吉林日报投稿：做强"绿氢+"产业  打造吉林振兴发展新引擎

| 文件 | 说明 |
|---|---|
| `稿件.md` | 正文源稿（作者姓名、联系方式为占位符） |
| `稿件.docx` | 由源稿生成的 Word，版式与已录用的《抢抓人工智能机遇  塑造吉林振兴发展新优势》一致 |
| `build-docx.js` | 生成脚本 |
| `事实核对表.md` | 稿中每个数据的出处，投稿前复核用 |

本仓库是公开仓库，所以**作者姓名和联系方式不入库**。生成带真实作者信息的投稿版：

```bash
node jilin-daily/build-docx.js /仓库外/作者信息.json /仓库外/投稿版.docx
```

`作者信息.json` 格式：`{"byline": "张三  李四", "info": ["作者：李四，……", "张三，……"]}`
