# 市调大赛参赛材料：雪域县域，消费何往

**题目**：《雪域县域，消费何往——西藏73区县市场潜力分层与居民消费需求调查》
**赛事**：“正大杯”第十七届全国大学生市场调查与分析大赛（本科组，组别按实际报名填写）

## 一、先说最重要的一点

市调大赛比的是**调查**。常见的报告评分表中，“方案设计”占 20 分、“调查实施”占 15 分，加起来超过三分之一；大赛也鼓励提交调查原始数据。
仓库里只有统计年鉴类的二手数据（区县面板、自治区宏观序列），**没有任何问卷数据**。Kris 仓库也看过了：里面是 CSMAR 上市公司数据和翻译稿，同样没有问卷数据，和市场调查主题也不搭。

所以这套材料是这样分工的：

| 部分 | 状态 |
|---|---|
| 背景、文献、指标体系、市场潜力指数、四类市场分层、稳健性检验 | **已完成**，全部用仓库现有数据算出 |
| 抽样设计（8 个样本县、946 户有效样本）、完整问卷、质量控制、进度 | **已完成**，抽样框就是上面的分层结果 |
| 第五部分“入户调查结果” | **只搭好框架**：表格、假设和分析方法已定，数值标红为【待调查完成后填写】 |

**不要用编造或模拟的数据填第五部分。** 评委会核对原始数据，答辩也会追问调查过程；一旦发现数据造假，会取消参赛资格。

## 二、文件

| 文件 | 用途 |
|---|---|
| `参赛报告-正文.docx` | 报告正文：标题页、摘要、目录、正文（目前约 15 页，第十六届本科组上限 65 页） |
| `参赛报告-附录.docx` | 附录（大赛要求和正文分开提交）：问卷、73 区县排名、数据清洗规则、代码说明、AI 使用说明 |
| `答辩PPT.pptx` | 答辩 PPT，16 页，宽屏 16:9，图表都是可编辑的原生图表 |
| `analysis.py` → `build_report.py` → `build_ppt.js` | 依次运行，可从原始数据重新生成全部结果和文件 |
| `output/` | 中间结果：`numbers.json`（报告和 PPT 的所有数字）、`T1`—`T8` 表、图 1—3 |

重新生成：

```bash
pip install pandas numpy scikit-learn matplotlib openpyxl python-docx
npm install
python3 analysis.py && python3 build_report.py
PPTX_SKILL=<pptx 技能目录> NODE_PATH=$PWD/node_modules node build_ppt.js
```
