### 第 6 个文件怎么整理（最关键）

目标是得到「每家公司、每年一行」的表，有 5 列：

| Stkcd | Year | Top1Shares | Top1PledgeShares | Top1Pct | TotalShares（可选） |
|---|---|---|---|---|---|
| 000001 | 2019 | 年末第一大股东持股数 | 其中处于质押状态的股数 | 第一大股东持股比例（%） | 总股本 |

推荐的取法，按优先级排：

1. **CSMAR「股东研究 → 十大股东」**：筛选统计截止日期为 12-31、持股排名为 1 的记录，取持股数量、持股比例，以及质押或冻结股份数量。这是年报口径，覆盖最全，也和主流文献一致。
2. 如果十大股东表里没有质押字段：用 **CSMAR「股东研究 → 股权质押」**的逐笔明细，筛出出质人为第一大股东、且在当年 12-31 仍未解押的记录，再把质押股数加总。
3. **Wind「股权质押」专题**：有「大股东累计质押数量」，可以直接导出，用来交叉核验。

没有质押的公司年度，Top1PledgeShares 填 0，不要留空。脚本会自动算出三个变量：Pledge = 质押股数 / 持股数；Pledge_Dum = 是否有质押；Pledge_Ratio2 = 质押股数 / 总股本。

```bash
pip install pandas numpy pyfixest openpyxl
```

## 三、预回归会给出什么

1. 描述性统计，以及质押逐年变化（能看到 2018 年前后的拐点）。
2. **基准回归 7 个设定**：无控制变量 → 加控制变量 → 是否质押虚拟变量 → 滞后一期 → 行业×年度固定效应 → 换现金口径 → 占总股本口径。
3. H3 融资约束交乘项、H4 国企/民营分组，同时给出两组的质押分布，以及 SA 方向核验。
4. 2018 新规处理强度 DID 快速版：基准、剔除 2018 年、行业×年度固定效应、"第一阶段"，外加逐年事件研究系数（用来看平行趋势）。
5. 自动生成一句话结论：系数方向、显著性，以及一个标准差对应的经济意义。

预回归只用来**判断方向、提前发现问题**。平仓压力、资金占用、现金价值模型这些机制检验要等后续数据齐全后再做。
