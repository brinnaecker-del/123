# 年报存档

数据资产入表论文用的数据，由年报自动提取而来。

## 数据资源提取结果.xlsx（主文件）

| 工作表 | 内容 |
|---|---|
| 说明 | 样本、方法、核对结果、人工修正记录 |
| 公司面板 | 每家公司一行（140 家），2024、2025 两年并列：存货 / 无形资产 / 开发支出项下数据资源、合计、来源，以及两年衔接核对 |
| 汇总 | 每份年报一行（236 份） |
| 明细行 | 每一行数据资源的原文、页码、单位，便于引用和核对 |
| 人工核对记录 | 对照年报原文逐条核对的 25 条：原文位置、核对结论、采用金额 |
| 原文摘录 | 年报中提到「数据资源」「数据资产」的段落及页码 |
| 诊断 | 未提取到金额的年报的线索 |

`数据资源_公司面板.csv` 是「公司面板」的纯文本版本，方便查看差异。

## 样本与口径

- 样本：高金《中国企业数据资产入表情况跟踪报告》2024 年度表 1.5（100 家，取 2024 年报）、2025 年度表 2.8（136 家，取 2025 年报），共 236 份，按股票代码去重 140 家。名单与股票代码对照见 `annual-report-scraper/data_assets_reports.py`。
- 年报原件：作者电脑 `E:\数据资产入表年报`（巨潮资讯网下载）。
- 提取程序：`annual-report-scraper/extract_data_resources.py`。金额优先取合并资产负债表「其中：数据资源」行，报表正文没有的依次取附注无形资产明细表、附注文字说明；统一折算为元。
- 核对：同一公司 2025 年报期初与 2024 年报期末，95 家衔接一致，唯一不一致的捷顺科技已查明（2024 年报填列的是原值）。2025 年报合计 37.87 亿元，与高金报告公布的 37.86 亿元基本一致；2024 年报合计 21.69 亿元。
- 人工核对（2026-10-09）：程序未取到或存疑的 25 份年报逐条对照原文核对，补录 6 份、确认 2 份为 0，记录见「人工核对记录」。核对用的页面由 `annual-report-scraper/extract_check_pages.py` 截取。

## 其他

- `2024年报/`、`2025年报/`、`清单.csv`：如需单份年报全文存档，用 `python annual-report-scraper/archive_reports.py 文件.pdf` 存入。
