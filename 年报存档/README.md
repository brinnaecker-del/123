# 年报存档

数据资产入表论文用的数据，由年报自动提取而来。

## 数据资源提取结果.xlsx（主文件）

| 工作表 | 内容 |
|---|---|
| 说明 | 样本、方法、核对结果、人工修正记录 |
| 公司面板 | 每家公司一行（140 家），2024、2025 两年并列：存货 / 无形资产 / 开发支出项下数据资源、合计、来源，以及两年衔接核对 |
| 汇总 | 每份年报一行（236 份） |
| 明细行 | 每一行数据资源的原文、页码、单位，便于引用和核对 |
| 人工核对记录 | 对照年报原文逐条核对的 25 条：原文位置、核对结论、采用金额 |
| 原文摘录 | 年报中提到「数据资源」「数据资产」的段落及页码 |
| 诊断 | 未提取到金额的年报的线索 |

`数据资源_公司面板.csv` 是「公司面板」的纯文本版本，方便查看差异。

## 样本与口径

- 样本：高金《中国企业数据资产入表情况跟踪报告》2024 年度表 1.5（100 家，取 2024 年报）、2025 年度表 2.8（136 家，取 2025 年报），共 236 份，按股票代码去重 140 家。名单与股票代码对照见 `annual-report-scraper/data_assets_reports.py`。
- 年报原件：作者电脑 `E:\数据资产入表年报`（巨潮资讯网下载）。
- 提取程序：`annual-report-scraper/extract_data_resources.py`。金额优先取合并资产负债表「其中：数据资源」行，报表正文没有的依次取附注无形资产明细表、附注文字说明；统一折算为元。
- 核对：同一公司 2025 年报期初与 2024 年报期末，95 家衔接一致，唯一不一致的捷顺科技已查明（2024 年报填列的是原值）。2025 年报合计 37.87 亿元，与高金报告公布的 37.86 亿元基本一致；2024 年报合计 21.37 亿元。
- 人工核对（2026-10-09）：程序未取到或存疑的 25 份年报逐条对照原文核对，补录 6 份、确认 2 份为 0，记录见「人工核对记录」。另修正神马股份 2024：程序因报表错位误取 31,366,800.60；原文「无形资产—其中：数据资源」行所印 26,772,194.00 / 22,007,854.81 实为开发支出余额（附注 p347–348 一致，CSMAR 亦记为开发支出），实际未列报数据资源，计为 0（高金名单应系照报表字面计入）。核对用的页面由 `annual-report-scraper/extract_check_pages.py` 截取。

## 财务数据与分析样本

| 文件 | 内容 |
|---|---|
| 财务数据提取结果.xlsx | `annual-report-scraper/extract_financials.py` 在作者电脑上的运行结果：236 份年报的总资产、营业收入、净利润、归母净利润、研发费用与研发投入，附「主要会计数据」核对列、明细行和诊断页 |
| 入表财务效应分析样本.xlsx / .csv | 论文入表利润效应检验（实证修改稿表 2 Panel A、表 3、图 2）用的数据：数据资源余额与财务数据合并，测算相对重要性、净利率影响、经营状态、盈亏反转；含变量说明与「财务数据人工核对」页 |
| 图1_研究框架.png、图2_全样本相对重要性与净利率影响.png、图3_事件研究.png | 实证修改稿图 1–图 3 |
| 实证结果/ | 各分析程序的输出（JSON）：`利润效应_table2.json`（表 3）、`入表选择与双重差分_tables34.json`（表 4、表 5）、`稳健性与异质性_robust.json`（表 2、表 6–表 8、图 3）、`分层安慰剂_placebo_strat.json`、`正文数字_facts.json`（正文零散数字、表 9）；程序见 `annual-report-scraper/analysis/csmar/README.md` |

- 核对：程序取到的每个数都位于报表原文对应行的第一、二个金额（逐行复核）；总资产、营业收入与年报「主要会计数据」逐一比对，不一致的均为主要会计数据一侧取到分季度表或截断数字，报表数无误。
- 人工核对（2026-10-09）：79 个字段按诊断页原文、主要会计数据或下一年报的上期数补录，主要是项目名折行（「归属于母公司股东的净 / 利润」）、金额与项目名上下错位（神马股份、山东玻纤 2024）、报表页无文字层（长江证券 2024、西部证券 2025、中国交建 2025）、程序误取追溯调整表（中国交建 2024）。依据逐条记在分析样本的「财务数据人工核对」页。长江证券 2024 年报的上年归母净利润取 CSMAR。
- 与 CSMAR 核对（2026-10-09，国泰安资产负债表、利润表）：236 份全部匹配。总资产 235 份分毫不差，另 1 份（神马股份 2024）差 0.03%，CSMAR 采用了追溯调整后的数；非金融企业营业收入 211/212 一致（上海钢联 2024 同为追溯调整），金融企业因 CSMAR「营业总收入」口径不同不可比；净利润 232 份一致，其余 4 份已改用 CSMAR 数（见「财务数据人工核对」）。
- 入表额（测算口径）为当期新增额＝期末－期初。2024 年绝大多数公司期初为 0；天威视讯、中远海科、中文在线、海天瑞声 4 家列示了 2024 年以前已资本化的期初余额，按差额计算（海天瑞声因此不再属于「全部费用化即由盈转亏」的公司，2024 年只有开普云一家）。2024 年期末合计 21.37 亿元，当年净增加 21.23 亿元。
- 2025 年报的上期数可能经追溯调整（如龙源电力、皖通高速、证券公司收入口径变更），与 2024 年报本期数不完全一致；分析一律采用各年报自身列示的数。
- 重现：`annual-report-scraper/analysis/` 下依次运行 `build_panel.py`（合并、补录）、`stats.py`（检验）、`table2.py`（表 3）、`fig2.py`（图 2）、`fig1.py`（图 1），参数见各文件开头；需要 CSMAR 的对照检验见 `annual-report-scraper/analysis/csmar/README.md`。
