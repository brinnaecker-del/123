# 年报存档

数据资产入表论文用的上市公司年报，由作者陆续发来后存放于此。

- 样本名单：高金《中国企业数据资产入表情况跟踪报告》2024 年度表 1.5（100 家，取 2024 年报）、2025 年度表 2.8（136 家，取 2025 年报），共 236 份；名单与股票代码对照见 `annual-report-scraper/data_assets_reports.py`。
- 全部 236 份原件在作者电脑 `E:\数据资产入表年报`，本文件夹只存已发来的部分。
- `2024年报/`、`2025年报/`：PDF 原件 + 同名 `.txt` 全文（`pdftotext -layout` 抽取，页与页之间以分页符隔开，可据此定位页码）。
- `清单.csv`：已存档年报的登记表（年度、代码、简称、页数、存档日期）。
- 存档方式：`python annual-report-scraper/archive_reports.py 文件1.pdf 文件2.pdf ...`
