## 一处待作者确认（另一处已查明）

**1. 发展子系统 UD 的小差异。** US、UE 各 10/10，唯独 UD 差 0.001—0.005。
反解各年隐含的 D2 与本底稿差 −2.38 至 +2.29 个百分点，无系统性方向，归不到任一单项
（D1 = 75237÷95749 = 78.58%、D2 = 21578÷23119 = 93.33%，2024 年两项均经公报核实无误）。
推测现稿的部分发展类原始值已较旧版更新。**请以现稿实际使用的发展类数值替换「1_基础数据」对应行，
全表将自动重算。** 该差异传导至 MPI 最大 0.002，不改变任何结论。

**2.〔已查明·无需处理〕§5(二) 的 0.229 属于哪一层。**
复算确认：论文的 0.229 系 **MPI 协调指数层**的差异（复算 0.2289，差 −0.0001），原文表述准确。
指标层为 0.6147、子系统层为 0.2484。修订稿已补明计算层级。
本工作簿「10_稳健性检验」按**指标层**计算，故显示 0.6147，与论文并不矛盾——两者层级不同。

## 使用方法

```bash
pip install openpyxl formulas
python3 build.py        # 重新生成底稿
python3 evaluate.py     # 离线逐格求值并与论文载值比对
```

在 Excel / WPS 中打开底稿即自动重算；公式已避免数组常量等兼容性写法。
