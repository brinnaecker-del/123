# 西藏三元协调评价 · 计算底稿

`西藏三元协调评价-计算底稿.xlsx` —— 与论文**现行方法**一致的可复现计算底稿，全部为活公式。
修改「1_基础数据」蓝色单元格后，11 张表全部自动重算。

> ⚠️ 原上传的 `data/计算底稿-旧版方法.xlsx` 使用的是**旧版方法**（极差标准化、组合权重加权合成、
> 修正耦合协调度 D=√(C′·T)、15 项指标），与现稿的方法、指标集与全部数值均不对应，
> **不可作为论文附件提交**。其「1_原始数据」表的原始数值有效，已并入本底稿。

## D5 口径：此前 UD 对不上的全部原因（已解决）

表 1 载 D5 为「发电量」、数据来源「统计公报（**规上工业主要产品产量**）」。
旧版计算文件误填为「**清洁能源发电量**」，两者口径不同——这正是此前发展子系统 UD
差 0.001—0.005 的全部原因。改用规上工业口径后，UD 由 2/10 变为 **10/10**。

已取自统计公报的六年（2016、2017、2020、2021、2023、2024）代入后，UD 与 MPI 各 6/6
精确吻合，反证口径判断正确。

## 使用方法

```bash
pip install openpyxl formulas
python3 build.py        # 重新生成底稿
python3 evaluate.py     # 离线逐格求值并与论文载值比对
```

在 Excel / WPS 中打开底稿即自动重算；公式已避免数组常量等兼容性写法。
