## 主要发现

1. 自有收入人均基尼 0.48—0.64，远高于 GDP（0.32—0.37）和支出（0.22—0.28）；区县财政自给率中位数仅 3.9%—5.1%。
2. 「均等化比率」2016 年 0.46 → 2018—2022 年 0.60—0.64 → 2024 年回落到 0.49：疫情期间支出被压平，之后重新拉开。
3. **周期不对称**：自有收入随 GDP 上升而上升（弹性 0.38），GDP 下降时却不降反升（−1.37），对称性检验 p = 0.003；逐一剔除 23 个下降样本、换 6 种稳健性设定，结论都成立（p ≤ 0.047）。支出对上升、下降都不敏感。
4. 人均 GDP 有 β 收敛（约 3.4%/年），没有 σ 收敛。
